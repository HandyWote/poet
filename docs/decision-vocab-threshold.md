# 决策记录：词表频率门槛 T 的选择

**日期**：2025-08-18（按项目时间线）
**决策**：词表只保留训练集中出现次数 ≥ 10 的字，其余并入 `<unk>`（即频率门槛 T = 10）
**结果词表**：7396 个真字 + 3 个特殊符（`<unk>`, `<bos>`, `<eos>`）= **7399**

---

## 1. 背景

训练 GPT 古诗模型前需构建字符级词表。训练集为宋诗 177,973 首。

## 2. 数据事实（统计自训练集）

- 训练集总字数：N = 13,208,472
- 不同字符数：V = 11,357
- 出现次数 < 10 次的字：K = 3,961 个，占字型 34.9%

## 3. 数学模型

记 `freq(c)` 为字符 c 在训练集中的出现次数。定义频率门槛 T：若 `freq(c) < T`，则 c 不进入词表，编码时归入 `<unk>`。

**语料损失**（被砍字的出现次数占总字数比例）：

```
L(T) = Σ_{freq(c) < T} freq(c) / N
```

**模型参数量**（6 层 Transformer，d=512，block_size=128，共享输入输出权重）：

```
M(T) = d × (V − K(T)) + d × 128 + n_layer × (12d² + 4d)

其中 K(T) = |{c : freq(c) < T}|，n_layer = 6
```

即词表只影响 embedding 与输出头（d × V'），主体参数（注意力 + 前馈 ≈ 18.9M）与词表无关。

**边际汇率**（每牺牲 1% 语料能换回多少 % 模型缩小）：

```
R(T) = (ΔM / M) / (ΔL / L)
```

## 4. 计算结果

| T | 剩余词表 | 语料损失 L(T) | 测试集 `<unk>` 率 | 模型参数 M(T) |
|---|---|---|---|---|
| 1 | 11,357 | 0.000% | 0.015% | 24.77M |
| **10** | **7,396** | **0.089%** | **0.097%** | **22.74M** |
| 100 | 4,441 | 0.968% | 0.974% | 21.23M |
| 250 | 3,266 | 2.412% | 2.414% | 20.62M |

区间汇率：

| 区间 | 1% 语料 ↔ 模型缩小 |
|---|---|
| T = 1 → 10 | ↔ 91% 模型 |
| T = 10 → 100 | ↔ 7.5% 模型 |
| T = 100 → 250 | ↔ 2.0% 模型 |

## 5. 决策依据

1. **可学习性**：每轮训练中字符 c 的学习机会 ≈ freq(c) 次。freq < 10 的字整轮训练学习机会不足 10 次，embedding 无法学到有效表示，保留无收益、只有参数成本。
2. **白捡区**：T ≤ 10 处于"1% 语料换 91% 模型"的超高性价比区；T > 10 后边际汇率急剧衰减（10 → 100 区间降至 7.5%），收益递减显著。
3. **测试集代价小**：测试集 `<unk>` 率实测 0.097%，对评测困惑度影响可忽略；若 T = 100，该比例升至 0.97%，困惑度将实打实受损。
4. **绝对量小**：T = 10 与 T = 250 相比模型仅差 2.1M 参数（≈ 8MB），对训练无实质影响——成本真实存在，但量级不足以主导决策。

## 6. 结论

选 T = 10：词表 7399（7396 字 + `<unk>`/`<bos>`/`<eos>`），训练集覆盖率 99.911%，测试集 `<unk>` 率 0.097%。

**验证方法**：`process/tokenizer.py` 的 `plot_distribution()` 可复现全部统计与图表（`data/poetry-set/distribution.png`）；本文所有数值可由 `uv run python process/tokenizer.py` 重新计算核对。
